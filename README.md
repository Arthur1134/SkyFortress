# Sky Fortress Ultimate

Pixel shmup campaign (HTML5). Play on [GitHub Pages](https://arthur1134.github.io/SkyFortress/).

**Version:** 0.3.10

## Play
- Pages: https://arthur1134.github.io/SkyFortress/
- Local: open `index.html` or use My Library Launcher

## Notes
